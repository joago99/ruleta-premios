# Ruleta de Premios

Página HTML standalone de una ruleta de premios con foto de la abuela en el centro.

## Características
- Configura la cantidad de jugadores (números del 1 al N)
- Título del premio personalizable
- Panel de configuración claro a la izquierda
- Ruleta grande y alegre a la derecha
- Foto de la abuela en el centro (incrustada como data URI)
- Historial de ganadores + botón "Reiniciar ganadores"
- Botón "GIRAR RULEJA" con animación

## Cómo usar
Abrí `index-nuevo.html` directamente en el navegador, o servilo:

```
python -m http.server 8080
```

Y navegá a `http://localhost:8080/index-nuevo.html`.

Archivo principal: `index-nuevo.html`
